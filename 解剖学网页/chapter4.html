第四章 · 工具知识

解剖学方位术语

医生描述器官位置用的"坐标系统"。学会了这些术语，你就能看懂CT报告和手术记录。

📖 本章导读

是什么？医学界统一的"坐标系统"——用标准化术语精确描述人体任何位置，避免歧义。
为什么重要？CT报告、手术记录、医学文献全部使用这套术语。不懂它，看病时医生说的话等于天书。
和我有什么关系？以后体检看到"L4-5椎间盘向左后方突出"，你能立刻知道是什么部位、什么方向。← 第3章 人体结构层次

一、为什么需要专门的方位术语？

日常生活中，我们说"上面""下面""左边""右边"，大家都懂。但在医学中，这样说是不行的。

病人站着的时候，肝脏在胃的"右边"。可是如果病人躺在手术台上，而你站在病人对面看，他的右边变成了你的左边。如果病人侧卧呢？"上下"又变了。——如果没有统一标准，每个人说的方位可能完全不一样，手术中就会出大问题。
所以解剖学规定了一个标准姿势，所有方位都以这个姿势为基准，不管病人实际上是站着、躺着还是趴着。

二、解剖学标准姿势

🧍 解剖学标准姿势

身体直立，面向前方，两眼平视前方，两足并拢，脚尖向前，上肢自然下垂于躯干两侧，手掌朝前。

注意最容易忽略的一点：手掌朝前！这会影响前臂的桡侧（拇指侧）和尺侧（小指侧）的判断。

不管病人实际是什么姿势，描述方位时都以标准姿势为准。医生说"心脏在胸腔前部偏左"，这个"前"指的是标准姿势下靠腹面的那一侧，即使病人正躺着面朝天。

三、基本方位术语详解

1. 上与下（头端与足端）

术语 含义 举例
上（Superior / 头侧 Cranial） 靠近头顶的方向 心脏位于膈肌的上方
下（Inferior / 足侧 Caudal） 靠近脚的方向 膀胱位于子宫的下方

2. 前与后（腹侧与背侧）

术语 含义 举例
前（Anterior / 腹侧 Ventral） 靠近身体前面（腹面） 胸骨在心脏的前方
后（Posterior / 背侧 Dorsal） 靠近身体后面（背面） 脊柱在食管的后方
CT报告常写"前纵隔""后纵隔""腹膜后间隙"，都用到前后方位。比如"腹膜后间隙占位"意思是在腹膜后面（靠近脊柱那一侧）发现了一个肿块。

3. 内侧与外侧

术语 含义 举例
内侧（Medial） 靠近身体正中线 小拇指在手的内侧（尺侧）
外侧（Lateral） 远离身体正中线 大拇指在手的外侧（桡侧）
想象一根线从头顶正中央沿着鼻尖、胸骨中间、肚脐一直画到两脚之间——这根线就是正中线。靠近这根线的就是"内侧"，远离它的就是"外侧"。

4. 近端与远端（四肢专用）

术语 含义 举例
近端（Proximal） 靠近躯干/四肢根部 肩关节是上肢的近端
远端（Distal） 远离躯干/四肢末端 手指是上肢的远端
骨折报告写"股骨远端骨折"，意思是大腿骨靠近膝盖那一端的骨折（远离躯干），而不是靠近髋关节的那一端。

5. 浅与深

术语 含义 举例
浅（Superficial） 靠近体表 皮肤是最浅的结构
深（Deep） 远离体表，靠近身体内部 股骨（大腿骨）是大腿最深的结构
从外到内就像剥洋葱：皮肤（最浅）→ 皮下脂肪 → 筋膜 → 肌肉 → 骨头（最深）。手术从浅层逐层切开，一层一层往深走。

四、三个基本切面

解剖学还定义了三个互相垂直的切面，用来描述"从哪个方向切开来看"：

切面 怎么切 看到什么 对应影像
矢状面（Sagittal） 前后方向竖着切，把人分成左右两半 可以看到器官的前后关系和上下关系 MRI矢状位
冠状面（Coronal） 左右方向竖着切，把人分成前后两半 可以看到器官的左右关系和上下关系 MRI冠状位
水平面/横断面（Transverse） 横着切，把人分成上下两半 可以看到器官的前后关系和左右关系 CT横断面（最常见）
想象切面包：矢状面是把面包从正中间竖着切开（左右各一半），冠状面是从面包侧面竖着切开（前后各一半），水平面是横着切（上下各一半，就像切汉堡）。
📱 CT报告常见表述翻译

"右肺下叶后基底段见磨玻璃结节"

→ 右边的肺 · 下面的那个叶 · 后部靠底的那个小区域 · 发现了一个像磨砂玻璃一样半透明的小结节

"肝右叶后段低密度灶"

→ 肝脏右边的叶 · 后面的那一段 · 有一个密度偏低的区域（可能是囊肿或其他东西）

"L4-5椎间盘向左后方突出"

→ 第4和第5腰椎之间的椎间盘 · 朝着左边偏后的方向 · 凸了出来（腰椎间盘突出症）

五、体腔的划分

人体内部有几个大的空腔，了解它们的划分有助于理解器官的位置：

1. 胸腔

位于膈肌以上，包含心脏、肺、大血管、食管、气管。胸腔被纵隔（中间的隔板，包含心脏等）分成左右两个胸膜腔，分别容纳左右肺。

2. 腹腔

位于膈肌以下，盆腔以上。包含胃、肠、肝、脾、胰、肾等。腹腔内壁有一层薄膜叫腹膜，像保鲜膜一样包裹着大部分腹腔器官。

3. 盆腔

腹腔的下方延续，被骨盆包围。包含膀胱、直肠，女性还有子宫、卵巢。

4. 颅腔和椎管

颅骨围成的颅腔容纳大脑，脊椎围成的椎管容纳脊髓。两者相连，里面充满脑脊液。

六、腹部的九分法

腹部范围很大，为了精确描述位置，医学上把腹部划分为9个区：

📐 腹部九分法

画两条水平线（一条过肋弓最低点，一条过两侧髂前上棘连线）和两条垂直线（过左右锁骨中点向下），把腹部分成9格：

左季肋区 腹上区（上腹部） 右季肋区
脾、左肾上部、结肠脾曲 胃、肝左叶、胰腺体部 肝右叶、胆囊
左腰区 脐区 右腰区
降结肠、左肾 小肠、腹主动脉 升结肠、右肾
左髂区 腹下区（下腹部） 右髂区
乙状结肠 膀胱、子宫（女性） 阑尾、盲肠
右髂区（右下腹）疼痛最经典的诊断是阑尾炎，因为阑尾就在这里。但阑尾炎初期往往是脐周疼（因为阑尾的内脏痛觉传入脊髓的节段对应脐周），过几小时后才转移到右下腹（变成局部腹膜刺激的体表痛）——这个"转移性右下腹痛"是阑尾炎的典型表现。
记住腹部九区的关键器官：右上肝胆、上腹胃、左上脾脏；右下阑尾、下腹膀胱/子宫。这是看急诊最实用的知识。

七、常见误区

❌ 医学里说的"左右"是面对病人的左右 ✅ 永远是以病人自己的左右为准！面对CT片子时，片子上标注的"R"是病人的右侧（你看到的画面左侧）。这是初学者最容易搞混的。
❌ "上"就是头的方向，"下"就是脚的方向（无论什么姿势） ✅ 所有方位都以"解剖学标准姿势"为基准。即使病人躺在手术台上，"上（superior）"依然指头端方向，"前（anterior）"依然指腹面方向。不随体位改变。

八、计算机类比

💻 程序员视角看方位术语
  • 标准姿势 ≈ 坐标系原点——就像CSS的 position: relative 建立参考系，所有方位都相对于这个"默认pose"来描述
  • 方位术语（上下/前后/内外） ≈ 三维坐标轴（X/Y/Z）——上下=Y轴，前后=Z轴，内外侧=X轴，每个器官都有一个三维坐标
  • 三个切面 ≈ 数组切片（Array Slicing）——矢状面是 body[:, :, x]，冠状面是 body[:, y, :]，水平面是 body[z, :, :]——三个维度各切一刀
  • 腹部九分法 ≈ CSS Grid 网格布局——把腹部看作 display: grid; grid-template: repeat(3, 1fr) / repeat(3, 1fr)，每个格子里放不同的"组件"（器官）
  • 近端/远端 ≈ DOM树的父子关系——近端=closer to root（躯干），远端=deeper child（指尖）
💡 本章核心要点

1. 所有方位以解剖学标准姿势为基准（直立、面前、掌心朝前）

2. 六对方位术语：上/下、前/后、内侧/外侧、近端/远端、浅/深

3. 三个切面：矢状面、冠状面、水平面（看CT/MRI必备）

4. 腹部九分法：定位腹部器官的"网格坐标"

5. 这些术语是医学的"语言"，后续所有章节都会用到
