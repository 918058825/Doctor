第十章 · 人体系统

生殖系统

男性和女性各有一套精密的生殖器官，负责产生生殖细胞、完成受精和孕育新生命——这是唯一一个以"物种延续"而非"个体生存"为目的的系统。

📖 本章导读

🔍 是什么 生殖系统是负责产生生殖细胞（精子/卵子）、分泌性激素、完成受精和孕育新生命的器官系统。
❓ 为什么要学 理解青春期发育、月经周期、避孕原理、不孕不育原因、常见生殖疾病的解剖学基础。
⚡ 有多重要 这是唯一不影响个体生存、但决定物种延续的系统。生殖系统疾病（前列腺增生、宫颈癌等）影响数亿人。

一、男性生殖系统

1.1 睾丸 —— 精子工厂和激素源

睾丸是男性最重要的生殖器官，左右各一个，位于阴囊内。它身兼双职：

  • 产生精子（外分泌功能）：睾丸内有大量弯曲的生精小管，总长度可达250米！精子就在这里经过约74天的发育过程产生。一个健康成年男性每天产生约2亿个精子。
  • 分泌雄激素（内分泌功能）：主要是睾酮（testosterone），由生精小管之间的间质细胞（Leydig细胞）分泌。睾酮负责男性第二性征（胡须、喉结、声音低沉、肌肉发达、骨骼粗壮等）和维持性功能。
为什么睾丸在体外？ 精子生成需要比体温低2-3℃的环境（约35℃）。阴囊就是一个精妙的"恒温器"：
• 冷了→ 提睾肌收缩，把睾丸拉近身体 + 阴囊皮肤收缩变皱（减少散热面积）
• 热了→ 提睾肌松弛，睾丸远离身体 + 阴囊皮肤舒展（增加散热面积）+ 汗腺分泌散热
长期高温环境（泡热水澡、桑拿、笔记本电脑放腿上、穿过紧的内裤）可能影响精子质量。

1.2 附睾 —— 精子的"培训学校"

贴附在睾丸后方的弯曲管道，展开后长达6米！精子从生精小管产生后，还是"半成品"——不能运动也不能受精。在附睾中经过约2周的旅程，精子逐渐获得运动能力和受精能力。成熟的精子储存在附睾尾部，等待排出。

1.3 输精管和射精管

从附睾延伸出来的管道，壁厚腔细，长约40-50厘米。输精管经过腹股沟管进入盆腔，在膀胱后方与精囊腺的排泄管汇合成射精管，穿过前列腺开口于尿道。

精子的旅程就像一条生产线：生精小管是"工厂"→ 附睾是"培训中心"→ 输精管是"运输管道"→ 射精管是"发射通道"。输精管结扎就是在阴囊段切断输精管并结扎——相当于切断了运输管道，精子出不来，但工厂照常运转（激素分泌和性功能完全不受影响）。

1.4 精囊腺

一对长椭圆形的囊状腺体，位于膀胱底的后方。分泌精囊液，是精液的主要成分（约占精液体积的60-70%）。精囊液含有：

  • 果糖：给精子提供能量（精子的"能量饮料"）
  • 前列腺素：促进女性生殖道蠕动，帮助精子运送
  • 凝固因子：射精后精液先凝固（防止从阴道流出），之后再液化（释放精子）

1.5 前列腺 —— 小器官大问题

栗子大小（约4×3×2厘米），位于膀胱下方，包裹着尿道起始部。分泌前列腺液（约占精液的20-30%），含锌、枸橼酸、蛋白水解酶等，有助于精子活力和精液液化。

前列腺增生（BPH）：几乎是老年男性的"标配"。前列腺体积逐渐增大→压迫其包裹的尿道→排尿困难（尿线变细、夜尿增多、排尿费力、尿不尽、尿滴沥）。统计数据：50岁以上男性约50%出现症状，80岁以上几乎100%有病理改变。这就像一条水管外面套了个越来越膨胀的橡皮圈，管腔被越挤越窄。
前列腺癌：男性最常见的恶性肿瘤之一。早期通常无症状，筛查手段包括：直肠指检（医生从直肠摸前列腺）和血清PSA（前列腺特异性抗原）检测。因为前列腺就贴着直肠前壁，所以从直肠能直接摸到它。

1.6 男性生殖系统路径总览

睾丸（产精子）
→
附睾（精子成熟）
→
输精管（运送）
→
射精管
→
尿道（排出）

途中汇合精囊液 + 前列腺液 = 精液（精子只占精液的约5%）

二、女性生殖系统

2.1 卵巢 —— 卵子工厂和激素源

左右各一个，位于盆腔内子宫两侧，扁卵圆形，约4×3×1厘米，重约6克。同样身兼双职：

  • 产生卵子：女性出生时卵巢内约有100-200万个原始卵泡，到青春期只剩约30万-40万个（大量自然退化），一生中只有约400-500个卵泡能成熟排卵。
  • 分泌激素：雌激素（促进女性第二性征、子宫内膜增殖、维持骨密度）和孕激素/黄体酮（维持妊娠、抑制子宫收缩）。
精子（男性）

大小：约 60μm（微米）

数量：每天产生约 2 亿个

产生方式：持续生产（青春期→老年）

存活时间：在女性体内约 48-72 小时

运动能力：有尾巴，能主动游动

卵子（女性）

大小：约 120μm（人体最大细胞！）

数量：一生仅排出约 400-500 个

产生方式：出生时已定，逐渐消耗

存活时间：排卵后约 12-24 小时

运动能力：无运动能力，靠输卵管纤毛运送

2.2 输卵管 —— 受精的"婚房"

连接卵巢和子宫的管道，长约10-12厘米，分四部分：

  • 漏斗部（伞部）：末端呈喇叭口形，有许多"手指状"突起（输卵管伞），排卵时靠近卵巢表面"捡拾"卵子
  • 壶腹部：最宽大的部分，受精的场所
  • 峡部：管腔最窄，输卵管结扎就在这里操作
  • 子宫部：穿入子宫壁的部分
宫外孕（异位妊娠）：受精卵没有正常到达子宫，而在输卵管内就着床发育。输卵管太细（管腔仅1-2mm）无法容纳胚胎→输卵管破裂→腹腔大出血→妇科最危险的急症之一。
主要原因：输卵管炎症→管腔粘连→受精卵"堵在路上"。
警示信号：停经后突然下腹剧痛 + 阴道出血 → 立即就医！

2.3 子宫 —— 胎儿的"宫殿"

位于盆腔中央，前为膀胱，后为直肠。形如倒置的梨，大小约7×5×3厘米。壁由三层构成：

  • 子宫内膜（最内）：月经和妊娠的"主角"。分功能层（每月增殖脱落=月经）和基底层（不脱落，负责再生）
  • 子宫肌层（最厚）：三层平滑肌交织。妊娠时可增大数十倍，分娩时强力收缩
  • 子宫外膜（最外）：浆膜
宫颈癌：几乎100%由高危型HPV（人乳头瘤病毒）持续感染引起。从感染到发展为癌需10-20年。
• 筛查：TCT + HPV检测，21岁以上女性应定期筛查
• 预防：HPV疫苗（9-45岁可接种），是唯一可通过疫苗预防的癌症之一
月经的本质（详解）：
① 增殖期（约第5-14天）：雌激素→内膜增厚
② 分泌期（约第15-28天）：排卵后孕激素→内膜进一步发育，准备接受受精卵
③ 月经期（约第1-4天）：未受精→黄体退化→激素骤降→内膜脱落出血
周期约28天（21-35天属正常），经量约30-80ml。

2.4 阴道

连接子宫和外阴的管道，长约7-9厘米。阴道壁有丰富的横行皱襞，弹性极大，分娩时可扩张到让胎头（直径约10cm）通过。阴道内正常存在乳酸杆菌，维持酸性环境（pH 3.8-4.5），抑制有害菌生长。

三、男女生殖系统对比

产生生殖细胞

男性器官：睾丸→精子

女性器官：卵巢→卵子

共同点：都是性腺，兼产激素

运送生殖细胞

男性器官：附睾→输精管

女性器官：输卵管

共同点：都是肌性管道

附属腺体

男性：精囊腺、前列腺

女性：前庭大腺

共同点：分泌液体辅助生殖

性激素

男性：睾酮为主

女性：雌激素 + 孕激素为主

共同点：男女都有雌/雄激素，只是比例不同

四、受精与早期发育

4.1 精子的"长征"

阴道出发（~2亿）
→
穿过宫颈（淘汰90%+）
→
子宫腔
→
输卵管壶腹部（仅~200个到达）

2亿精子中最终只有约200个到达受精地点，淘汰率99.9999%。只有1个精子能穿透卵子。一旦进入，卵子立即发生"透明带反应"——阻止其他精子进入。

4.2 从受精到着床

受精卵（第1天）
→
细胞分裂
→
桑葚胚（第3-4天）
→
囊胚（第5-6天）
→
着床（第6-7天）

着床后胚胎分泌HCG（人绒毛膜促性腺激素）——验孕棒检测的就是它。

五、常见误区与FAQ

❌ 输精管结扎后没有性功能了 ✅ 结扎只切断运输管道，睾丸照常分泌睾酮，性欲和性功能完全不受影响
❌ 月经是"排毒" ✅ 月经是子宫内膜周期性脱落出血，和"排毒"没有任何关系
双胞胎是怎么形成的？
同卵双胞胎：1个受精卵分裂成2个胚胎，基因完全一样。异卵双胞胎：2个卵子各被1个精子受精，基因不同，可能性别不同。
避孕药的原理是什么？
含雌/孕激素，通过负反馈抑制排卵 + 使宫颈黏液变稠 + 子宫内膜变薄。📎 见第12章·负反馈

六、计算机类比

💻 程序员视角看生殖系统
  • 精子+卵子 ≈ 两个 git branch，各带23条染色体
  • 受精 ≈ git merge，合并为完整的46条染色体
  • 透明带反应 ≈ mutex lock，防止多精受精（并发写入=数据损坏）
  • 月经周期 ≈ cron job，每28天执行一次，受精成功则取消后续任务
  • HCG ≈ ACK 确认包——"我已成功着床"
  • 胎盘 ≈ API Gateway，母体和胎儿血液不直接混合，通过接口层交换数据
💡 本章核心要点

1. 男性：睾丸产精子+睾酮 → 附睾成熟 → 输精管运送 → 前列腺包裹尿道

2. 女性：卵巢产卵子+雌/孕激素 → 输卵管壶腹部受精 → 子宫孕育

3. 精子vs卵子：2亿/天 vs 400个/一生

4. 月经 = 子宫内膜脱落（不是排毒！）

5. 受精在输卵管壶腹部，第6-7天着床子宫

6. 宫颈癌由HPV引起，可疫苗预防
