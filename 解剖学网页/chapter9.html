第九章 · 人体系统

泌尿系统 —— 人体的超级净水站

两个拳头大小的肾脏，每天过滤180升血液，精准调控体内水、电解质和酸碱平衡。

📖 本章导读

🔍 是什么 泌尿系统是人体的"净水站"——过滤血液中的代谢废物、调节水电解质和酸碱平衡、生成尿液排出体外。
❓ 为什么要学 肾结石、尿路感染、肾衰竭是常见病。肾脏还调节血压和造血，与📎 循环系统和📎 内分泌系统密切相关。
⚡ 有多重要 肾脏每天过滤180升血液。双肾衰竭=毒素堆积→尿毒症→必须透析或换肾，否则致命。
180升/天 原尿生成量
1.5升/天 终尿排出量
99% 水分被重吸收
100万/个 肾单位数量

泌尿系统由四个部分组成：

肾脏（生成尿液）
→
输尿管（运送尿液）
→
膀胱（储存尿液）
→
尿道（排出尿液）

一、肾脏 —— 核心器官

1.1 位置和外形

肾脏有两个，位于腹膜后间隙（不在腹膜腔内），脊柱两侧，第12胸椎到第3腰椎水平。右肾比左肾略低（因为右侧有肝脏压着）。每个肾约拳头大小，蚕豆形，重约150克。

很多人以为肾在腰的两侧偏下——其实肾的位置比想象的要高，上端几乎到了最下面几根肋骨的水平。后腰部的疼痛未必是肾的问题，更多是腰肌劳损或椎间盘的问题。当然，肾结石的绞痛确实会放射到腰部。

1.2 肾脏的内部结构

把肾脏纵切开来看：

  • 肾皮质：外层，颜色较深（红棕色），含有大量肾小球和肾小管近端，是过滤血液的主要区域。
  • 肾髓质：内层，颜色较浅，由10-15个锥体形的肾锥体（肾金字塔）组成，主要是肾小管的袢和集合管，负责浓缩尿液。
  • 肾盂：肾脏中央的漏斗形空腔，收集各肾锥体形成的尿液，向下延续为输尿管。

1.3 肾单位 —— 肾脏的功能单位

每个肾约有100万个肾单位，每个肾单位是一个独立的"微型净水器"，包含：

🔬 肾单位的结构

肾小体 = 肾小球（一团毛细血管球）+ 肾小囊（包裹在肾小球外面的双层囊）

肾小管 = 近端小管 → 髓袢（U形管） → 远端小管 → 集合管

1.4 尿液形成的三步

①滤过

在哪里：肾小球

做什么：血液被"过筛子"，水和小分子（葡萄糖、尿素、离子）通过，大分子（蛋白质、血细胞）留下

比喻：筛子过滤——大的留下，小的通过

②重吸收

在哪里：肾小管

做什么：把有用的东西（99%的水、全部葡萄糖、大部分离子）"捡回来"送回血液

比喻：在垃圾堆里把有价值的东西捡回来

③分泌

在哪里：肾小管

做什么：把血液中一些废物和多余的离子主动"扔进"小管里

比喻：再往垃圾袋里扔几样不要的东西

想象肾脏是一个超级垃圾分拣站：第一步把所有东西都倒出来（滤过→180升原尿），第二步工人把有价值的东西捡回来放回传送带（重吸收→99%的水和几乎所有的葡萄糖），第三步再把漏网的垃圾额外扔进垃圾袋（分泌），最终只有1.5升真正的"垃圾"（终尿）被排出。

1.5 肾脏的其他功能

肾脏不只是排尿，它还是一个重要的内分泌器官：

  • 调节血压：分泌肾素，激活肾素-血管紧张素-醛固酮系统（RAAS），升高血压。很多降压药就是针对这个系统。
  • 促进造血：分泌促红细胞生成素（EPO），刺激骨髓产生红细胞。肾衰竭时EPO不足→贫血。
  • 调节钙磷代谢：活化维生素D（变成有活性的骨化三醇），促进肠道吸收钙。
肾功能衰竭（尿毒症）：当肾脏损伤到无法有效过滤血液时，代谢废物（尿素、肌酐等）在血液中堆积，同时水电解质和酸碱平衡紊乱。患者需要定期做血液透析（用机器代替肾脏过滤血液）或肾脏移植。

二、输尿管

连接肾盂和膀胱的细长管道，长约25-30厘米，直径约5毫米。靠管壁平滑肌的蠕动把尿液一波一波地从肾脏送到膀胱。

输尿管有三个狭窄处（和食管类似，结石最容易卡在这里）：

  1. 肾盂输尿管连接处（起始处）
  2. 越过髂血管处（跨过骨盆入口）
  3. 穿入膀胱壁处（最窄，约2mm）
输尿管结石：肾结石从肾脏掉下来卡在输尿管狭窄处，引起输尿管痉挛性收缩→肾绞痛（被描述为"人生最剧烈的疼痛之一"），疼痛从腰部放射到下腹、腹股沟甚至大腿内侧，常伴恶心呕吐、血尿。小结石可能自行排出，大的需要碎石或手术。

三、膀胱

位于骨盆腔内，耻骨联合后方。是一个可伸缩的肌性囊袋，壁上有逼尿肌（平滑肌），排尿时收缩。

空虚

四、尿道

从膀胱到体外的排尿通道。男女差异很大：

男性尿道

长度：18-20 厘米

功能：排尿 + 排精（共用通道）

感染风险：相对低（尿道长，细菌不易到达膀胱）

女性尿道

长度：3-5 厘米

功能：只排尿

感染风险：高！（尿道短且直，细菌容易上行到膀胱）

尿路感染（UTI）在女性中非常常见，约50%的女性一生中至少会经历一次。原因就是解剖结构：女性尿道短（3-5cm），且开口靠近阴道和肛门。预防措施包括多喝水、不憋尿、便后从前向后擦拭。

五、水电解质平衡——肾脏的"精密调控"

肾脏不只是排废物，它还是维持体内环境稳定（内环境稳态）的核心器官：

  • 调水：渴了/出汗多→ADH增加→肾脏少排水→保水。喝太多水→ADH减少→肾脏多排水→排水。
  • 调钠/钾：醛固酮促进保钠排钾。高钾血症可致心脏骤停（非常危险）。
  • 调酸碱：肾脏排出多余的酸（H⁺）、保留碳酸氢盐（HCO₃⁻），维持血液pH在7.35-7.45的精确范围。
肾脏五大功能口诀：排废物、调水盐、控酸碱、调血压（肾素）、促造血（EPO）。
简记为："排、调、控、压、血"

六、常见误区

❌ "腰疼就是肾不好" ✅ 绝大多数腰疼是腰肌劳损或腰椎问题。肾脏位置比想象的高（几乎到肋骨下缘），真正的肾区叩击痛通常在后腰的肋脊角处。
❌ "多喝水能排毒" ✅ 适量饮水确实帮助肾脏排出代谢废物和预防结石，但过量饮水（水中毒）反而会导致血液被稀释→低钠血症→严重可致脑水肿和死亡。正常人每天1.5-2升水即可。

七、计算机类比

💻 程序员视角看泌尿系统
  • 肾脏 ≈ 数据库清理服务 + 日志管理——持续过滤血液（数据流），分拣有用/无用的物质（数据/垃圾），回收有用的（缓存），排出无用的（删除日志）
  • 肾小球滤过 ≈ SELECT * FROM blood WHERE molecular_weight < 70000——按分子量筛选，大分子（蛋白质）留下，小分子通过
  • 肾小管重吸收 ≈ ROLLBACK——把误删的有用数据（葡萄糖、99%的水）找回来
  • 180升→1.5升 ≈ 数据压缩率 99.2%——每天处理180L原始数据，最终只输出1.5L精简结果
  • 肾素-血管紧张素系统 ≈ 负载均衡器——根据血压（系统负载）自动调节，压力低→增加血管阻力（加服务器），压力高→反之
  • 膀胱 ≈ 缓冲区（Buffer）——数据先存到缓冲区，达到阈值（300ml→尿意）后才flush到外面
💡 本章核心要点

1. 泌尿系统 = 肾脏 + 输尿管 + 膀胱 + 尿道

2. 肾单位（肾小球+肾小管）是功能单位，每个肾100万个

3. 尿液形成三步：滤过→重吸收→分泌，180升原尿→1.5升终尿

4. 肾脏还调节血压（肾素）、促造血（EPO）、活化维生素D

5. 输尿管三个狭窄处是结石易卡部位

6. 女性尿道短→尿路感染风险高
