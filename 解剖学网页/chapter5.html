第五章 · 人体系统

运动系统 —— 人体的钢筋混凝土框架

骨骼是支架，关节是铰链，肌肉是发动机。三者配合，让你能站立、行走、奔跑、写字。

📖 本章导读

是什么？骨（支架）+ 关节（铰链）+ 骨骼肌（发动机）三位一体，支撑身体并完成所有运动。
为什么重要？运动系统疾病（腰椎间盘突出、骨质疏松、关节炎）是程序员久坐办公的高发问题。
和我有什么关系？理解脊柱、关节的结构，才能真正明白"为什么久坐伤腰"以及"怎么科学锻炼"。← 第4章 方位术语
206 块骨头（成人）
600+ 块骨骼肌
~40% 体重占比（肌肉）
230+ 个关节

一、骨（Bone）—— 人体的钢梁

1.1 骨的功能

骨头不是死的"石头"，它是活的组织，有血管有神经，一直在新陈代谢。

功能 说明 举例
支撑 骨骼是整个身体的支架 脊柱撑起整个躯干，就像帐篷的中心柱
保护 骨骼围成腔体保护重要器官 颅骨→大脑，肋骨→心肺，骨盆→膀胱子宫
运动 作为肌肉收缩的杠杆 前臂骨头就是杠杆，肘关节是支点
造血 骨髓（红骨髓）生产血细胞 红细胞、白细胞、血小板都在骨髓中产生
储存矿物质 储存钙和磷 血钙低时骨头释放钙补充；骨质疏松就是钙丢失过多

1.2 骨的分类（按形态）

类型 形态特点 代表骨 分布
长骨 中间细长两端膨大，像一根"棒子" 股骨（大腿骨）、肱骨（上臂骨）、胫骨（小腿骨） 四肢
短骨 各方向差不多等长，像"骰子" 腕骨、跗骨 手腕、脚踝
扁骨 宽而薄，像"盾牌" 颅骨、肋骨、胸骨、肩胛骨 保护部位
不规则骨 形状复杂，不归入上面任何一类 椎骨、髋骨 脊柱、骨盆

1.3 骨的结构

一根长骨从外到内的结构：

骨膜（最外层）
→
密质骨（坚硬外壳）
→
松质骨（海绵状）
→
骨髓腔（中心空腔）
  • 骨膜：包在骨头最外面的一层膜，含有丰富的血管和神经，负责营养骨头和感知疼痛。骨折疼痛主要是骨膜被损伤。骨膜还含有成骨细胞，是骨折后修复愈合的关键。
  • 密质骨：坚硬致密的骨质，是骨头强度的来源。就像钢管的管壁。
  • 松质骨：在骨头两端和内部，像海绵一样有很多孔隙，减轻重量的同时仍有很好的支撑力。
  • 骨髓：在骨髓腔和松质骨的孔隙中。儿童的骨髓全是红骨髓（造血），成年后四肢长骨骨干中的红骨髓逐渐被脂肪替代变成黄骨髓（不造血），但在特殊情况下黄骨髓可以重新变成红骨髓。
骨质疏松症：随着年龄增长，骨头中的钙质逐渐流失，松质骨变得更"疏松"，骨头变脆。最常见的骨折部位是：脊椎椎体（压缩性骨折，驼背）、股骨颈（老人摔倒后髋部骨折，致残率很高）、桡骨远端（摔倒时手撑地）。

1.4 全身骨骼的区域划分

206块骨头分布在全身，大致分三个区域：

区域 骨头数量 主要骨骼
中轴骨骼（头+躯干） 80块 颅骨（29块）、脊柱（26块椎骨）、胸骨（1块）、肋骨（24块）
上肢骨 64块（左右各32块） 锁骨、肩胛骨、肱骨、桡骨、尺骨、腕骨(8)、掌骨(5)、指骨(14)
下肢骨 62块（左右各31块） 髋骨、股骨、髌骨、胫骨、腓骨、跗骨(7)、跖骨(5)、趾骨(14)

1.5 脊柱——身体的"中心柱"

脊柱由26块椎骨组成（儿童33块，成年后部分融合），是人体的中轴支撑。从上到下：

颈椎 7块
→
胸椎 12块
→
腰椎 5块
→
骶骨 1块（5块融合）
→
尾骨 1块（3-4块融合）

脊柱从侧面看有四个弯曲：颈曲（向前凸）、胸曲（向后凸）、腰曲（向前凸）、骶曲（向后凸），形成一个S形。这个S形增加了脊柱的弹性，起到减震作用。

"你有几块颈椎？"——不管是人、长颈鹿、还是鲸鱼，几乎所有哺乳动物都只有7块颈椎。长颈鹿脖子那么长，也是7块，只不过每块椎骨都非常长。
腰椎间盘突出：椎骨之间有椎间盘（像一个软垫），如果椎间盘后面的纤维环破裂，里面的髓核组织就会突出来，压迫旁边的神经根，引起腰痛和腿部放射痛（坐骨神经痛）。最常见在L4-5和L5-S1。

二、关节（Joint）—— 骨头之间的铰链

2.1 骨连接的方式

骨和骨之间的连接叫"骨连接"，分两大类：

类型 特点 举例
直接连接（不动/微动） 骨头之间靠纤维组织、软骨或骨质直接连在一起 颅骨之间的骨缝、椎骨之间的椎间盘、耻骨联合
间接连接（关节/滑膜关节） 两骨之间有间隙（关节腔），可以自由活动 肩关节、肘关节、膝关节、髋关节等

2.2 关节的基本结构

一个典型的关节有三个必备结构：

🔧 关节三要素

关节面：两块骨头相对的面，表面覆盖光滑的关节软骨（透明软骨），减少摩擦，起缓冲作用。软骨没有血管和神经，损伤后自我修复能力很差。

关节囊：包裹整个关节的纤维膜+滑膜层的"袋子"。外层是纤维膜（坚韧），内层是滑膜（分泌滑液）。

关节腔：关节囊内的密封空间，含有少量滑液（关节液），起润滑和营养关节软骨的作用。

很多关节还有辅助结构：

  • 韧带：连接两块骨头的"绳子"，加固关节，限制过度运动。比如膝关节的前后交叉韧带。
  • 关节盘/半月板：在关节腔内的一块软骨垫，增加稳定性，改善关节面的吻合。膝关节的内外侧半月板是最典型的。
  • 滑囊：减少肌腱和骨头之间摩擦的"小水袋"。
半月板损伤：膝关节在弯曲状态下突然旋转（比如踢球时变向），最容易损伤半月板。半月板血供差（内2/3没有血管），撕裂后自愈能力很弱，严重的需要关节镜手术。

2.3 重要关节

关节 连接的骨头 特点 常见问题
肩关节 肱骨头+肩胛骨关节盂 全身活动范围最大的关节，但也最容易脱位 肩关节脱位（肱骨头从关节盂中滑出）
肘关节 肱骨+桡骨+尺骨 铰链关节，主要做屈伸运动 网球肘（肱骨外上髁炎）
髋关节 股骨头+髋臼 杵臼关节，活动范围大且稳定 老年人股骨颈骨折后可能需要换人工髋关节
膝关节 股骨+胫骨+髌骨 全身最大最复杂的关节 前交叉韧带损伤、半月板撕裂、骨性关节炎

三、骨骼肌（Skeletal Muscle）—— 人体的发动机

3.1 骨骼肌的基本原理

骨骼肌的两端通过肌腱（致密结缔组织，像"绳子"一样坚韧）附着在骨头上。肌肉收缩时，把两端的骨头拉近，就产生了运动。

起点和止点：肌肉附着在骨头上的两个端点。起点（近端，相对固定的一端）和止点（远端，运动时移动的一端）。肌肉收缩时，止点向起点靠近。
把手臂想象成一台起重机：上臂骨是"吊臂"，肘关节是"铰链"，肱二头肌是"钢缆"，前臂和手是"吊钩和货物"。肌肉（钢缆）收缩缩短，拉动前臂（吊钩）绕肘关节弯曲，就是屈肘动作。

3.2 主动肌和拮抗肌

大多数运动都是成对的肌肉协作完成：

角色 说明 屈肘时的例子
主动肌 完成动作的主要肌肉 肱二头肌收缩
拮抗肌 与主动肌方向相反，需要放松配合 肱三头肌放松
协同肌 辅助主动肌的肌肉 肱肌也参与屈肘
固定肌 固定起点所在的骨头不动 三角肌和肩袖肌群固定肩关节

3.3 重要的肌肉群

头面部

  • 表情肌：面部的薄肌肉，止点在皮肤上（不是骨头上），收缩时牵动面部皮肤产生表情。微笑、皱眉、惊讶，都是不同表情肌配合的结果。面瘫（面神经受损）时，一侧面部表情肌瘫痪，眼睛闭不上、嘴角歪斜。
  • 咀嚼肌：咬合和咀嚼食物用的肌肉，主要是咬肌和颞肌。用力咬牙时摸自己的腮帮子，鼓起来的就是咬肌。

颈部

  • 胸锁乳突肌：颈部两侧最明显的肌肉，转头和低头时用到。歪脖子（斜颈）就是一侧胸锁乳突肌挛缩或过度紧张。

躯干

  • 胸大肌：胸部最大的肌肉，做俯卧撑和推的动作主要靠它。
  • 背阔肌：背部最大的肌肉，做引体向上和拉的动作主要靠它。
  • 腹直肌：就是大家追求的"八块腹肌"，其实每个人都有，只是被脂肪盖住了。
  • 竖脊肌：脊柱两侧的长条形肌群，维持直立姿势。久坐后腰背酸痛，就是竖脊肌疲劳。
  • 膈肌：分隔胸腔和腹腔的穹顶形肌肉，是最重要的呼吸肌。膈肌收缩→胸腔扩大→吸气。

上肢

  • 三角肌：包裹肩关节的肌肉，让肩膀看起来圆润。打针（三角肌注射）就是打在这里。
  • 肱二头肌："二头肌"，屈肘和前臂旋后。
  • 肱三头肌：上臂后面的肌肉，伸肘（推东西的动作）。

下肢

  • 臀大肌：人体最大的肌肉，站立、上楼梯、跑步时发力。
  • 股四头肌：大腿前面，伸膝关节。踢球时发力最多的肌肉。
  • 腘绳肌：大腿后面，屈膝关节。跑步时容易拉伤。
  • 小腿三头肌：小腿后面（腓肠肌+比目鱼肌），踮脚和跑步蹬地靠它。小腿肚子抽筋就是这里痉挛。
记住几个"之最"：最大的肌肉→臀大肌；最长的肌肉→缝匠肌（从髋部斜跨到小腿内侧）；最小的肌肉→镫骨肌（在中耳，只有1毫米长）。

四、常见误区

❌ 骨头是死的，不会变化 ✅ 骨头是活的器官，一直在新陈代谢（破骨细胞吸收旧骨，成骨细胞建造新骨）。成人的骨骼大约每10年完全更新一轮。运动负荷刺激成骨，不运动则骨量下降（宇航员在太空失重环境中每月骨量丢失1-2%）。
❌ 拉伸/掰手指会导致关节炎 ✅ 多项研究表明掰手指（使关节腔产生气泡破裂的声音）不会增加关节炎风险。但暴力拉伸确实可能损伤韧带和肌腱。

五、计算机类比

💻 程序员视角看运动系统
  • 骨骼 ≈ 机箱/PCB板——提供结构支撑，固定所有"元器件"（器官），同时保护核心部件（颅骨保护CPU=大脑）
  • 关节 ≈ 铰链/万向节（Gimbal）——允许在特定自由度上运动。肩关节=3自由度万向节（球窝关节），肘关节=1自由度铰链（只能弯曲伸直）
  • 骨骼肌 ≈ 伺服电机（Servo Motor）——接收控制信号（神经冲动）→ 产生定量的位移和力矩
  • 肌腱 ≈ 连接线/排线——把电机（肌肉）的力传递到机械臂（骨头）上
  • 主动肌 vs 拮抗肌 ≈ H桥驱动——电机正转反转需要两组开关交替工作，肌肉的屈伸也是成对协作
  • 脊柱S形曲线 ≈ 避震器/减震弹簧——服务器机架用橡胶减震垫吸收震动，脊柱曲线吸收行走跑步的冲击力
💡 本章核心要点

1. 运动系统 = 骨 + 关节 + 骨骼肌

2. 骨的功能：支撑、保护、运动、造血、储存矿物质

3. 关节三要素：关节面、关节囊、关节腔

4. 肌肉通过肌腱附着在骨头上，收缩拉动骨头产生运动

5. 主动肌和拮抗肌成对工作，一个收缩一个放松

6. 脊柱是身体中轴，7颈12胸5腰+骶尾
