📖 解剖学术语词典

收录本学习平台涉及的核心术语，支持搜索和按系统筛选。遇到不懂的词，来这里查！

解剖学Anatomy基础
研究人体正常形态结构的科学。"解"=剖开，"剖"=分析。是所有医学学科的基础。
→ 第1章
组织Tissue基础
由形态和功能相似的细胞及细胞间质组成的结构。人体四大基本组织：上皮组织、结缔组织、肌肉组织、神经组织。
→ 第3章
器官Organ基础
由不同组织组合而成、执行特定功能的结构单元。如心脏包含肌肉组织、上皮组织、结缔组织和神经组织。
→ 第3章
解剖学标准姿势Anatomical Position基础
身体直立、面朝前方、两眼平视、双足并拢、上肢自然下垂、手掌朝前。所有方位术语的参考基准。
→ 第4章
矢状面Sagittal Plane基础
前后方向的纵切面，将人体分为左右两部分。MRI矢状位图像即从这个方向切割观察。
→ 第4章
密质骨/松质骨Compact / Spongy Bone运动
密质骨是坚硬致密的骨外壳，提供强度；松质骨在骨端内部呈海绵状，减轻重量同时保持支撑力。
→ 第5章
关节腔Joint Cavity运动
关节囊内的密封空间，含有少量滑液，起润滑和营养关节软骨的作用。
→ 第5章
椎间盘Intervertebral Disc运动
椎骨之间的纤维软骨垫，中央是胶状的髓核，外围是坚韧的纤维环。起缓冲减震作用。纤维环破裂→椎间盘突出。
→ 第5章
蠕动Peristalsis消化
消化管壁平滑肌的波浪式收缩运动，把食物从口腔方向推向肛门方向。倒立也能吞咽食物就是靠蠕动。
→ 第6章
幽门螺杆菌Helicobacter pylori (H.pylori)消化
能在胃酸环境中生存的细菌，是慢性胃炎和胃/十二指肠溃疡的主要病因。可通过碳14呼气试验检测。
→ 第6章
胆汁Bile消化
由肝脏分泌、储存于胆囊的消化液。主要功能是乳化脂肪（把大脂肪滴打散成小滴），增大脂肪酶的作用面积。
→ 第6章
肺泡Alveolus呼吸
肺内最小的气体交换单元，约7亿个，总面积约100㎡。壁极薄（0.2-0.5μm），紧贴毛细血管，O₂和CO₂在此扩散交换。
→ 第7章
膈肌Diaphragm呼吸
分隔胸腔和腹腔的穹顶形骨骼肌，是最重要的呼吸肌。收缩→胸腔扩大→吸气；舒张→胸腔缩小→呼气。打嗝=膈肌痉挛。
→ 第7章
窦房结Sinoatrial Node (SA Node)循环
位于右心房的特殊心肌组织，是心脏的"天然起搏器"，自动发放电冲动，决定心跳频率（60-100次/分）。
→ 第8章
冠状动脉Coronary Artery循环
专门为心肌供血的动脉，从主动脉根部发出。冠状动脉粥样硬化→冠心病→心绞痛/心肌梗死。
→ 第8章
淋巴结Lymph Node循环
淋巴管上的"过滤站"，含大量免疫细胞，过滤淋巴液中的细菌和异物。感染时肿大（如感冒时颈部淋巴结肿大）。
→ 第8章
肾单位Nephron泌尿
肾脏的基本功能单位，由肾小体（肾小球+肾小囊）和肾小管组成。每个肾约100万个肾单位。完成滤过、重吸收和分泌。
→ 第9章
肾小球滤过率(GFR)Glomerular Filtration Rate泌尿
单位时间内两肾生成的超滤液量，正常约125ml/min。是衡量肾功能最重要的指标。GFR下降=肾功能减退。
→ 第9章
受精Fertilization生殖
精子和卵子在输卵管壶腹部结合的过程。约2-3亿精子出发，最终只有一个能穿透卵子完成受精。
→ 第10章
月经周期Menstrual Cycle生殖
女性约28天为一周期的生殖准备过程。包括月经期（子宫内膜脱落）、增殖期（内膜修复增厚）、分泌期（内膜为着床做准备）。
→ 第10章
突触Synapse神经
神经元之间的信号传递结构。突触前膜释放神经递质→穿过突触间隙→与突触后膜受体结合→传递信号。类似API调用。
→ 第11章
髓鞘Myelin Sheath神经
包裹神经轴突的绝缘层，使神经冲动以跳跃式传导，速度从2m/s提升至120m/s。多发性硬化症=髓鞘被免疫系统攻击。
→ 第11章
交感/副交感神经Sympathetic / Parasympathetic神经
自主神经系统的两个分支。交感="战斗逃跑"（心率↑血压↑瞳孔散大），副交感="休息消化"（心率↓消化↑），两者像跷跷板互相拮抗。
→ 第11章
激素Hormone内分泌
由内分泌腺分泌、通过血液运输、作用于靶器官的化学信使。微量但效果显著（如1mg甲状腺激素就能加速全身代谢）。
→ 第12章
负反馈Negative Feedback内分泌
内分泌最核心的调节机制。靶腺激素水平升高→抑制上级（下丘脑/垂体）分泌→激素减少→抑制解除→激素再升高。类似空调恒温器。
→ 第12章
胰岛素Insulin内分泌
胰岛B细胞分泌的唯一能降低血糖的激素。促进细胞摄取葡萄糖和合成糖原。缺乏或抵抗→糖尿病。
→ 第12章
视锥细胞/视杆细胞Cone / Rod Cells感觉
视网膜上的两类感光细胞。视锥（600万）负责彩色视觉和细节（明视觉），视杆（1.2亿）负责暗光下的黑白视觉（暗视觉）。
→ 第13章
耳蜗Cochlea感觉
内耳的螺旋形结构，内含基底膜和毛细胞。声波振动→基底膜振动→毛细胞将机械能转为电信号→听觉。不同频率在基底膜不同位置引起共振。
→ 第13章
