消化道症状自查

根据你的不适部位和症状特征，找到可能的原因和对应章节——不是诊断，是给你提供一个参考方向。

本工具仅供健康教育参考，不能替代医生诊断。如症状持续、严重，或出现文末的"红旗症状"，请及时就医。

第一步：你的不适在哪个区域？

🟡 上腹部症状（胃区）

上腹痛/不适，什么时候最明显？
饭后加重，饱胀感明显
常见 可能是 功能性消化不良 或 慢性胃炎。 如有 HP 阳性，先治疗 HP。 → 第3章 胃炎、第2章 幽门螺杆菌
空腹或夜间痛，进食后缓解
常见 十二指肠溃疡的典型规律。 → 第3章 胃炎与胃溃疡
持续性隐痛，与进食关系不明显，伴体重下降
需就医 年龄 >40岁 + 体重下降，需要排除 胃癌，尽早做胃镜。 → 第5章 胃癌
服用止痛药（布洛芬/阿司匹林等）后出现
常见 NSAIDs 药物损伤胃黏膜。需要在医生指导下加用胃黏膜保护剂或换药。 → 第3章 胃溃疡、药物说明

🟠 胸骨后症状（食管区）

胸骨后不适，如何描述？
烧心感（胸骨后灼热）、反酸，饭后或平躺时加重
常见 胃食管反流病（GERD）的典型症状。 → 第4章 胃食管反流
慢性咳嗽、声音嘶哑、清晨恶心，但没有明显烧心
常见 GERD 的非典型表现，容易被误诊为咽喉炎或哮喘。 → 第4章 胃食管反流
吞咽困难，固体或液体都难以下咽
需就医 需要排除食管狭窄或食管病变，应做胃镜检查。
胸痛剧烈，与体位/呼吸有关，伴有出汗
急诊 先排除心脏问题！胸痛+出汗+放射到左臂，立即急诊心内科。

🟢 下腹部症状（肠区）

下腹部不适，主要是哪类症状？
腹泻+腹痛，与压力/情绪相关，排便后好转，无血便
常见 肠易激综合征（IBS-D 腹泻型）的典型模式。 → 第6章 肠易激综合征
便秘，3天以上不排便，排便费力
常见 功能性便秘。先调整膳食纤维和饮水，无效再考虑用药。 → 第7章 便秘、泻药说明
便血（大便带血），鲜红色，排便时滴血
常见 多数是痔疮（最常见原因）。但如年龄 >45岁或有家族史，需排除结肠病变，建议肠镜。 → 第8章 结直肠癌
便血（暗红色或柏油样黑便），伴腹痛或消瘦
需就医 暗红便/黑便提示消化道出血位置较高，需要尽快就医和检查。 → 第5章 胃癌、第8章 结直肠癌
腹泻，发烧，有不洁饮食史
常见 可能是急性肠胃炎（感染性）。多喝水，通常3-5天自愈。高热不退或便血需就医。

🟣 右上腹症状（肝胆区）

右上腹不适，如何描述？
饭后（尤其是油腻食物后）右上腹剧痛，可放射到右肩/背
需就医 胆绞痛的典型表现。尽快就医，超声检查确认。 → 第10章 胆结石
右上腹持续疼痛+发热
急诊 可能是急性胆囊炎，需要急诊处理和住院评估。 → 第10章 胆囊炎
体检发现转氨酶（ALT/AST）升高，有超重/饮酒史
常见 可能是脂肪肝。做腹部超声和肝功能评估。 → 第9章 脂肪肝
右上腹+皮肤/眼白发黄（黄疸）
急诊 黄疸提示胆管问题或肝脏病变，需要紧急评估。立即就医。

🔵 弥漫性/全腹症状

全腹不适，最主要的特征？
腹胀，喜欢放屁，与豆类/乳制品有关
常见 可能是产气食物不耐受或乳糖不耐受（乳制品后腹泻/腹胀）。 → 第6章 IBS 及 FODMAP 食物
腹痛急性发作+全腹板硬（腹肌紧张）
急诊 可能是腹膜炎，立即急诊！

🚨 红旗症状——这些情况立即就医

⚠️ 不要等待，立即就诊或急诊

  • 吐血或柏油样黑便：上消化道出血，急诊
  • 大量鲜血便：下消化道出血，急诊
  • 腹痛+高热+黄疸：胆管炎，急诊
  • 腹痛+腹肌板硬：腹膜炎，急诊
  • 不明原因体重下降超过5kg：需排除恶性肿瘤，尽快就医
  • 持续吞咽困难：需要胃镜排除食管病变
  • 45岁以上首次出现消化道症状：建议做胃镜/肠镜
  • 家族中有胃癌/结直肠癌：提前10年筛查

✅ 就医时，告诉医生这些信息

  • 症状持续了多长时间
  • 与饮食的关系（饭前/饭后/油腻后）
  • 有没有发热、体重下降、便血
  • 目前在服用什么药物（特别是止痛药）
  • 家族中有没有消化道肿瘤病史
  • 有没有幽门螺杆菌感染史
