三、技术架构（已落地）
----------------------------------------------------------------
前端：
  - 纯静态 HTML + CSS + JS，无框架
  - 托管：Netlify（免费，自定义域名 qiuxueshaonian.com）
  - 风格：深色主题（dark mode），移动端优先

用户系统：
  - 平台：Supabase（替代原计划的 LeanCloud）
  - 注册方式：手机号（+86）+ 密码（内部转为 {手机号}@qxsn.user 格式存储）
  - 无需邮箱验证，注册即可使用

数据库（Supabase）：
  - 表：activation_codes
    字段：id / code / is_used / bound_phone / bound_at / created_at
  - RLS策略：anon 角色可 SELECT / INSERT / DELETE（供前端验证使用）
  - RPC函数：
     bind_activation_code(input_code, input_phone)  返回 ok/used/invalid
     reset_password_with_code(input_phone, input_code, new_password)  返回 ok/invalid/not_found

四、授权码系统
----------------------------------------------------------------
格式：MMDD + 4位随机字母数字（如 0403A8K2）
      MMDD = 生成日期，方便对账查询
生成工具：manage-codes.ps1（本地 PowerShell 脚本，已 gitignore）
后台管理：admin.html（本地使用，已 gitignore）
  - 功能：查询/删除指定码、批量生成、查看未使用/已使用列表、复制、勾选删除

激活流程：
  用户在小红书购买  收到授权码
   打开 qiuxueshaonian.com  注册账号（手机号+密码）
   进入 redeem.html 输入授权码
   系统验证码存在且未使用  绑定手机号  标记已用
   解锁全站内容，永久有效

忘记密码流程：
  输入手机号 + 持有的授权码 + 新密码
   验证授权码与手机号绑定关系
   重置 Supabase 账号密码

六、权限控制逻辑（auth.js）
----------------------------------------------------------------
每个付费页面顶部设置：
  window._REQUIRE_LOGIN = true;
  window._AUTH_ROOT = '../';

auth.js 行为：
  - 检查 Supabase 登录态
  - 未登录  显示遮罩 + 弹窗（3种模式：登录 / 注册 / 忘记密码）
  - 已登录且已激活  放行，正常显示内容
  - 已登录但未激活  提示前往 redeem.html 兑换授权码

顶部导航（仅根目录 index.html 注入）：
  - 求学少年 Logo + 首页 + 我的账号 + 日夜模式切换 + 汉堡菜单
  - 汉堡展开：5个模块快速入口
  - 子页面不注入，各模块有自己的导航栏（高度统一 44px）
