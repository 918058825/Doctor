【核心钩子】
眼、耳、鼻、舌、皮肤——五套传感器阵列，让我们感知这个世界的色彩、声音、气味、滋味和触感。
没有感觉输入，大脑就是一台没有键盘鼠标的计算机。

────────────────────────────
13.1  眼——视觉器官
────────────────────────────

眼球三层壁：
  外膜——角膜（前 1/6，透明，屈光最强）+ 巩膜（后 5/6，「眼白」，保护）
  中膜——虹膜（有颜色，调节瞳孔）+ 睫状体（调节晶状体曲度）+ 脉络膜（营养视网膜）
  内膜（视网膜）——视锥细胞（感颜色，集中在中央凹）+ 视杆细胞（感明暗，周边）

视觉形成：
光线 → 角膜折射 → 瞳孔控光量 → 晶状体对焦 → 视网膜成像 → 视神经传导 → 枕叶「看到」

眼睛 = 相机：角膜+晶状体=镜头，瞳孔=光圈，视网膜=感光芯片，枕叶=图像处理器

常见眼科问题：
  近视——眼球前后径过长，像落在视网膜前，凹透镜矫正
  远视——眼球前后径过短，像落在视网膜后，凸透镜矫正
  白内障——晶状体浑浊，手术更换人工晶体
  青光眼——眼压升高→视神经受损→不可逆失明（定期检查！）

近视预防最有效方法：每天增加 2 小时户外活动（自然光抑制眼轴增长）

────────────────────────────
13.2  耳——听觉 + 平衡器官
────────────────────────────

外耳：耳廓（收集声波）→ 外耳道（约 2.5cm）→ 鼓膜（振动发声）

中耳：
  三块听小骨（人体最小的骨头！）：锤骨 → 砧骨 → 镫骨
  → 杠杆链，把鼓膜振动放大约 22 倍
  咽鼓管：平衡气压（飞机起降时吞咽/打哈欠→打开→不难受）

内耳（迷路）：
  耳蜗——听觉：振动→淋巴液波动→毛细胞→颞叶听觉中枢
  前庭——感受直线加速度（电梯、汽车）
  半规管（3 个互相垂直）——感受旋转加速度

晕车/晕船原理：
  眼睛说「没在动」vs 内耳说「在运动」→ 大脑信息矛盾 → 恶心呕吐
  解决方法：看窗外运动的风景（让视觉和前庭信息一致）

────────────────────────────
13.3  鼻——最特殊的感觉！
────────────────────────────

嗅觉 = 唯一不经过丘脑直接到达大脑皮层的感觉！
→ 直接到达边缘系统（掌管记忆和情绪）
→ 嗅觉与记忆的联系是所有感觉中最直接最强烈的

「普鲁斯特效应」：闻到某种气味突然想起某段记忆——完全有解剖学依据！

────────────────────────────
13.4  舌——味觉器官
────────────────────────────

约 10,000 个味蕾，五种基本味觉：
  甜（能量）、酸（变质预警）、苦（有毒警告，最敏感）、咸（矿物质）、鲜（蛋白质）

【被广泛传播的错误】「舌头味觉地图」——舌尖尝甜、舌根尝苦是错的！
→ 舌头每个部分都能感受所有五种味道
→ 这个错误来源于 1901 年一篇德国论文的误读，流传超过 100 年

────────────────────────────
13.5  皮肤——最大的感觉器官
────────────────────────────

面积约 1.5-2 平方米，重约 4 公斤，占体重 16%

四种皮肤感觉：
  触觉——迈斯纳小体（精细触觉，指尖密集）
  压觉——帕奇尼小体（深压和振动）
  温度觉——冷觉感受器（数量比温觉多）
  痛觉——游离神经末梢（最广布，「报警器」）

两点辨别觉：
  指尖——能分辨 2mm 间距（感受器密度极高）
  后背——需要 60mm 以上（感受器稀疏）
  这叫「皮层放大」：大脑对重要部位分配更多处理资源

五种感觉 vs 是否经过丘脑中转：
  视觉/听觉/味觉/触觉——经过丘脑
  嗅觉——不经丘脑！这是嗅觉特殊的解剖学原因

【常见误区】
  ❌ 掏耳朵是清洁好习惯
  ✅ 耳屎有保护作用会自行排出；频繁掏耳可能损伤耳道或推深耵聍

  ❌ 近视是因为看书太多
  ✅ 近视根本原因是眼轴变长（遗传+环境）；每天 2 小时户外活动最有效

第十四章  融会贯通
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【核心钩子】
人体不是九个互不相关的「部门」，
而是一台随时协同运转的整体机器。

────────────────────────────
14.1  九大系统一览
────────────────────────────

  系统          核心器官                    一句话功能
  ────────────────────────────────────────
  运动系统      骨、关节、肌肉              支撑身体、保护内脏、完成运动
  消化系统      胃、肠、肝、胰              摄取食物、消化吸收、排出残渣
  呼吸系统      鼻、喉、气管、肺            吸入 O₂、排出 CO₂、气体交换
  循环系统      心脏、血管、血液            运输氧气营养、带走废物
  泌尿系统      肾、输尿管、膀胱            过滤血液、排出废物、调水电解质
  生殖系统      睾丸/卵巢、子宫            产生生殖细胞、孕育新生命
  神经系统      脑、脊髓、神经              接收信息、处理信息、发出指令
  内分泌系统    垂体、甲状腺、肾上腺        分泌激素、长效化学调节
  感觉器官      眼、耳、鼻、舌、皮肤        感知外界信息（视听嗅味触）

────────────────────────────
14.2  三个场景——系统协同的真实案例
────────────────────────────

【跑步时，全身发生了什么】
  运动系统  → 骨骼肌收缩
  神经系统  → 大脑发出指令，小脑协调平衡
  循环系统  → 心跳加速，为肌肉输送更多 O₂
  呼吸系统  → 呼吸加深加快
  内分泌系统→ 肾上腺素分泌增加
  泌尿系统  → 出汗多→肾脏减少排水→尿量减少
  消化系统  → 暂时被抑制（交感神经兴奋）

【吃饭后，全身发生了什么】
  消化系统  → 口腔→胃→小肠逐步消化
  内分泌系统→ 血糖升高→胰岛素分泌
  循环系统  → 消化道血流增加
  神经系统  → 副交感兴奋→促进胃肠蠕动（饭后犯困=血液集中到消化道）

【感冒发烧，全身发生了什么】
  内分泌系统→ 下丘脑调高体温设定点→发烧（高温不利于病原体繁殖）
  神经系统  → 头痛、全身酸痛（炎症因子作用于神经）
  呼吸系统  → 鼻黏膜充血→鼻塞；气管分泌增多→咳嗽
  循环系统  → 心率加快（体温每升 1℃，心率约增加 10-15 次/分）
  消化系统  → 食欲下降（资源集中到免疫系统）

14.4  终极类比——人体 = 分布式微服务系统
────────────────────────────

  神经系统    ≈  CPU + OS Kernel（信息处理中枢）
  内分泌系统  ≈  消息队列（Kafka）（异步化学信使）
  循环系统    ≈  网络基础设施（TCP/IP + 交换机）
  呼吸系统    ≈  电源系统（PSU）（断供即死）
  消化系统    ≈  ETL 数据管道（原料→可用格式）
  泌尿系统    ≈  数据库清理 + 日志轮转
  运动系统    ≈  机械臂/执行器（Actuator）
  生殖系统    ≈  CI/CD Pipeline + Fork 仓库
  感觉器官    ≈  传感器阵列（摄像头/麦克风/陀螺仪）
  免疫系统    ≈  防火墙 + IDS + 杀毒软件

整个人体 = 一个高可用的分布式系统：
  自动扩缩容（负反馈调节）
  故障转移（代偿机制）
  日志监控（疼痛 = error log）
  自修复能力（伤口愈合 = self-healing container）
