一、用户定位与核心要求
----------------------------------------------------------------

用户画像：
  - 26岁，嵌入式软件工程师，计算机背景
  - 已完成解剖学14章学习
  - 非医学生，学习目的是理解自己的身体，提升认知广度
  - 不以考试为目的，功利性导向（对生活有用才重点讲）
  - 健身爱好者，有手汗症手术史（ETS切T3/T4交感神经）

核心要求（用户原话）：
  - "理解为主，帮我提升这方面的认知"
  - "可以多举例或者使用通俗语言去形容"
  - "每个章节按照常见或者重要程度去讲，重要的多一点案例"
  - "不以考试为目的，是理解"
  - "内容尽量不重叠，专注讲生理就行"
  - "后续可能会合并链接生理学解剖学"

----------------------------------------------------------------
二、内容定位原则
----------------------------------------------------------------

原则1：通俗优先，术语其次
  每个生理机制先用大白话说清楚，再引出专业名词。
  例：不直接说"心脏的Frank-Starling机制"，
      而是说"心脏有个特性：给它的血越多，它就跳得越有力——
      就像皮筋拉得越长弹回来越猛"，然后再注明这叫Frank-Starling定律。

原则2：案例密度高
  重要章节（循环、神经、内分泌）每个知识点配至少1个生活案例。
  案例来源优先选用户亲身经历：
    - 手汗症手术 → 神经生理章节重点解析
    - 体脂低怕冷 → 体温代谢章节解析
    - 吃不胖 → 内分泌/代谢章节解析
    - 晕车 → 感觉生理章节解析
    - 咖啡因 → 神经生理/睡眠章节解析

原则3：专注生理，不重复解剖
  解剖学已讲过结构，生理学只说"这个结构怎么工作"。
  例：解剖学讲了"肾脏由肾小球、肾小管组成"，
      生理学只讲"肾小球为什么能过滤血液、肾小管怎么把有用的东西收回来"。
  每章开头用一句话链接解剖（"结构你已经知道了，现在讲它怎么运作"），不展开。

原则4：病理埋伏笔
  在关键机制后加小提示："如果这个机制出问题 → 就会变成XXX"
  目的是为后续病理学学习打基础，不深入讲，只埋一个钩子。

原则5：CS类比贯穿全书
  每章至少1个用计算机/电路/程序来类比的模块。
  用户有计算机背景，这类类比理解效率最高。

----------------------------------------------------------------
三、章节规划（12章）
----------------------------------------------------------------

【第一阶段：基础核心 · 3章】

第1章 · 稳态与调节
  核心：稳态（Homeostasis）、负反馈、正反馈
  重要程度：⭐⭐⭐⭐⭐（全书底层逻辑，每章都用到）
  案例：
    - 发烧为什么会自然退（负反馈）
    - 血糖为什么能保持稳定（负反馈）
    - 分娩越来越强烈（正反馈）
    - 大失血越流越多（正反馈失控）
  CS类比：负反馈 = PID闭环控制系统

第2章 · 细胞与电信号
  核心：细胞膜、离子通道、静息电位、动作电位、全或无定律
  重要程度：⭐⭐⭐⭐（神经和肌肉的硬件基础）
  案例：
    - 局部麻醉为什么能止痛（阻断Na+通道，动作电位无法产生）
    - 心律不齐的本质（异常电信号）
    - 高钾血症为什么危险（影响静息电位）
  CS类比：
    - 静息电位 = 电容的待机充电状态（-70mV）
    - 动作电位 = 数字脉冲信号（全或无 = 1/0二进制）
    - 离子通道 = 逻辑门，电压达到阈值才打开

第3章 · 血液
  核心：血液成分、红细胞携氧、血型、凝血三阶段
  重要程度：⭐⭐⭐（基础，相对轻松）
  案例：
    - 献血400ml为什么安全（造血储备机制）
    - 去高原为什么红细胞增多（低氧 → EPO分泌 → 红细胞增生）
    - 割伤为什么几分钟就不流血（凝血三步：血管收缩→血小板聚集→凝血瀑布）
    - 血型不合输血为什么致命（抗原抗体反应→溶血）

【第二阶段：四大系统 · 4章】

第4章 · 循环生理
  核心：心脏自律性、心动周期、心输出量、血压形成与调节
  重要程度：⭐⭐⭐⭐⭐（最重要的章节之一）
  案例（多）：
    - 心脏离体后为什么还能跳（窦房结自律性）
    - 蹲久站起眼前一黑（体位性低血压，压力感受器反射不及时）
    - 跑步心率从70→150的调节路径
    - 运动员静息心率55的原因（每搏量大，不需要跳那么快）
    - 量血压为什么要坐着安静5分钟（消除交感激活的影响）
    - 用户手汗症手术对心率的轻微影响（T3/T4交感支配心脏加速的部分）
  CS类比：心脏 = 双泵并联系统（左泵高压→体循环，右泵低压→肺循环）

第5章 · 呼吸生理
  核心：肺通气动力、气体交换、O2/CO2运输、呼吸调节（CO2驱动）
  重要程度：⭐⭐⭐⭐
  案例：
    - 憋气为什么是难受（CO2堆积）而不是缺氧
    - 高原反应的完整机制（低氧→低CO2→呼吸暂时抑制→头痛）
    - 跑步"岔气"的真实原因（膈肌痉挛）
    - 跑步"极点"怎么突破（无氧→有氧切换时的调节滞后）
    - 过度换气为什么会头晕（CO2吹走太多→脑血管收缩）
  CS类比：气体交换 = 浓度梯度驱动的DMA内存传输，不需要主动消耗能量

第6章 · 消化生理
  核心：消化液分泌调节、三大营养素吸收、脑肠轴
  重要程度：⭐⭐⭐⭐
  案例：
    - 紧张为什么肚子痛/腹泻（脑肠轴，交感抑制消化）
    - 咖啡为什么促进排便（刺激胃结肠反射+胆囊收缩素）
    - 吃蛋白质和吃糖为什么饱腹感不同（消化速度与激素分泌差异）
    - 空腹喝咖啡为什么胃不舒服（直接刺激胃酸分泌）
    - 为什么饭后不适合剧烈运动（血液重新分配）
  侧重：与健身营养直接相关的吸收机制多讲

第7章 · 泌尿生理
  核心：肾小球滤过、肾小管重吸收、尿液浓缩机制、酸碱平衡
  重要程度：⭐⭐⭐（略烧脑，通俗化处理）
  案例：
    - 每天过滤180L血液只生成1.5L尿（99%重吸收）
    - 喝水多尿多/少喝尿黄的调节机制（ADH抗利尿激素）
    - 运动大量出汗为什么补白开水不够（低渗透压→细胞水肿）
    - 喝酒为什么尿多（酒精抑制ADH）
    - 憋尿的危害（膀胱扩张→逆流风险）
  CS类比：肾脏 = 先做全量拷贝（滤过），再精准删除不需要的（分泌），留下有用的（重吸收）

【第三阶段：调控系统 · 3章】

第8章 · 神经生理
  核心：突触传递、常见神经递质、反射弧、交感/副交感对抗
  重要程度：⭐⭐⭐⭐⭐（和用户个人经历关联最强）
  案例（最多）：
    - 用户手汗症手术完整机制（大脑→脊髓→T3/T4交感节→手掌汗腺，切断后的代偿）
    - 咖啡因阻断腺苷受体→不困了（但腺苷还在积累）
    - 多巴胺：不是"快乐"，是"期待"（刷手机上瘾的神经机制）
    - 血清素：情绪稳定器，缺乏→抑郁（抗抑郁药的原理）
    - 去甲肾上腺素：紧张时心跳加速的信使
    - 膝跳反射为什么不经过大脑（脊髓反射弧）
    - 为什么专注时间有限（前额叶皮层的能量消耗）
  CS类比：
    - 突触 = 消息队列，神经递质 = 消息体
    - 兴奋性突触 = 发布消息，抑制性突触 = 取消消息
    - 交感神经 = 系统高性能模式，副交感 = 省电/充电模式

第9章 · 肌肉生理
  核心：肌丝滑行理论、钙离子触发机制、肌肉力学特性、疲劳恢复
  重要程度：⭐⭐⭐⭐（直接服务健身）
  案例：
    - 力量训练为什么让肌肉变大（肌丝增粗，不是肌纤维数量增加）
    - DOMS延迟酸痛：不是乳酸，是微撕裂引发的炎症反应
    - 乳酸的真相：其实是能量底物，不是废物
    - 热身为什么重要（温度升高→酶活性提高→收缩速度快→受伤风险低）
    - 抽筋的机制（和解剖学信号解码对应，但这里讲电生理原因）
    - 为什么举重憋气（Valsalva动作稳定腹压的原理）
  CS类比：肌丝滑行 = 两个齿条相向滑动，总长度缩短但齿条本身不变

第10章 · 内分泌生理
  核心：激素分类与作用机制、胰岛素-血糖轴、皮质醇昼夜节律、甲状腺素
  重要程度：⭐⭐⭐⭐⭐（解释用户很多个人疑问）
  案例：
    - 皮质醇早晨峰值（CAR）的完整机制（已和用户讨论过，网页里系统化）
    - 用户吃不胖的解释（甲状腺素→基础代谢率→热量消耗）
    - 胰岛素的工作机制（钥匙开门模型）
    - 压力大为什么长痘/掉发（皮质醇升高→免疫/激素紊乱）
    - 睾酮与健身（合成代谢，训练后分泌的意义）
    - 褪黑素与睡眠（蓝光抑制褪黑素→推迟入睡）
  CS类比：激素 = 广播消息，只有携带对应受体（接收器）的细胞才会响应

【第四阶段：整合 · 2章】

第11章 · 感觉生理
  核心：感受器换能原理、视觉/听觉/痛觉/前庭觉的生理机制
  重要程度：⭐⭐⭐（轻松章节，有趣）
  案例：
    - 辣为什么是痛觉（TRPV1受体被辣椒素激活，和被热激活的受体是同一个）
    - 晕车的完整机制（前庭-视觉-本体感觉三路信号冲突，和用户亲身经历对应）
    - 为什么眼睛看了强光再进暗处暂时看不见（视紫红质漂白恢复需要时间）
    - 耳鸣的可能机制（毛细胞受损→异常自发放电）
    - 用户油耳的生理基础（顶泌腺分泌，ABCC11基因）

第12章 · 体温与能量代谢
  核心：基础代谢率（BMR）、产热散热机制、体温调节中枢、发烧生理意义
  重要程度：⭐⭐⭐⭐
  案例：
    - 用户体脂低（<10%）为什么怕冷（皮下脂肪绝热层薄，散热快）
    - 发烧要不要马上吃退烧药（38.5°C以下有免疫意义，不要急着退）
    - 运动后为什么很久还在出汗（体温惯性，散热继续）
    - 男性基础代谢比女性高的原因（肌肉量差异）
    - 用户"吃不胖"的热力学解释（热量守恒，消耗>摄入）

四、每章固定模块设计
----------------------------------------------------------------

模块1：📌 导读
  - 这章讲什么（1句话）
  - 和解剖学哪章对应（1句话，不展开）
  - 学完你能解释什么（3个具体问题，钩子式）

模块2：🔬 核心机制
  - 主体内容
  - 通俗语言为主，流程图/示意图（用HTML+CSS实现）
  - 每个机制后附生活案例

模块3：🖥️ CS类比
  - 每章1~2个专门的类比模块
  - 代码块风格排版，视觉上有辨识度

模块4：⚠️ 常见误区
  - 每章2~4个，纠正网上流传的错误认知

模块5：🔮 病理预告
  - 轻量，1~3条"如果这里出问题 → XXX疾病"
  - 不深入讲，只埋钩子

模块6：🔗 章节导航
  - 上一章 / 下一章
  - 本章对应解剖学章节（标注，暂不链接）

五、工具页规划
----------------------------------------------------------------

✅ 做（必须有）：
  glossary.html · 生理学术语词典
    - 收录80+常用术语（比解剖学词典更多，生理学概念密度高）
    - 按系统分类筛选
    - 每个术语标注"出现在第X章"

✅ 做（生理学特色）：
  mechanisms.html · 核心机制图解库
    - 把全书最重要的10~15个机制做成可视化流程图
    - 例：负反馈调节、动作电位传导、血压调节反射弧、凝血瀑布
    - 不用翻章节，单独查阅
    - 配合章节内流程图一起使用，形成"速查图谱"

  scenarios.html · 生活场景解析（换角度切入）
    - ✅ 确认做，但与解剖学场景页切入角度不同：
    - 解剖学场景页：这个场景里"哪些结构参与了"
    - 生理学场景页：这些结构"用了什么机制"完成任务
    - 场景选择上优先选解剖学没有深入讲的角度，或选新场景
    - 例：睡眠的生理学（睡眠分期/记忆巩固机制，解剖学只讲了褪黑素）
    - 例：运动极限的生理学（无氧阈/乳酸阈/摄氧量上限机制）
    - 例：情绪的生理学（多巴胺/血清素/皮质醇联合作用）
    - 例：饥饿与饱腹的生理学（瘦素/胃饥饿素/血糖调节）

❌ 不做：
  body-monitor.html · 读懂身体数据
    - 用户反馈：数据平时看不到，不好理解，取消
  quiz.html · 自测问答 → 用户目的不是考试，不做
  compare.html · 系统对比 → 对比内容嵌入章节内，不单独做页面

六、视觉风格规划
----------------------------------------------------------------

与解剖学网站的区分：
  - 解剖学：深蓝紫色调（#1e3a8a → #312e81）→ 偏"结构/静态"感
  - 生理学：深青蓝色调（#0c4a6e → #0e7490）→ 偏"流动/动态"感
  - 两个网站打开后颜色不同，能立刻区分

复用解剖学的基础组件：
  - nav.js 导航脚本逻辑
  - info-box 系列（blue/green/yellow/red）
  - chapter-card 章节卡片
  - breadcrumb 面包屑
  - site-footer 页脚

生理学新增组件（因为内容特性）：
  - flow-diagram：流程箭头图（展示调节回路，如负反馈循环）
  - mechanism-box：机制框（和CS类比模块统一排版）
  - data-card：数据卡片（展示正常值范围，颜色警示区间）

七、设计决策记录（已与用户确认 · 2026-03-28）
----------------------------------------------------------------

决策1：❌ 取消 body-monitor.html
  原因：数据平时看不到，不容易理解，对用户意义不大。

决策2：✅ scenarios.html 做，切入角度与解剖学不同
  解剖学场景页：讲哪些结构参与了
  生理学场景页：讲这些结构用什么机制运作
  选题上优先选解剖学未深入的角度或全新场景。

决策3：✅ 章节内容长，全面丰富，通俗易懂
  - 每章目标内容量：4000~8000字（HTML正文）
  - 重要章节（循环/神经/内分泌）不设上限，讲透为止
  - 每个知识点要写出推导过程，不只给结论
  - 案例要具体，来龙去脉说清楚
  - 用户一章一章单独确认，不批量生成
  - 生成时可主动询问"这部分需要展开吗"

决策4：✅ 章节内做流程图（HTML+CSS纯代码实现）
  - 调节链（A→B→C→D）做成流程箭头图
  - 负反馈回路做成环形闭合图
  - 颜色编码：正向刺激绿色箭头，抑制红色箭头，结果框蓝色
  - mechanisms.html收录全书重要流程图，章节内也同步嵌入

八、建设顺序建议
----------------------------------------------------------------

建设顺序：
  第0步：style.css + nav.js（基础样式和导航）
  第1步：index.html（生理学主页）
  第2步：chapter1.html → chapter2.html → … → chapter12.html
          每章单独生成，用户确认后再进行下一章
  第3步：glossary.html（术语词典）
  第4步：mechanisms.html（核心机制图解库）
  第5步：scenarios.html（生活场景解析）

节奏约定：
  - 用户一章一章指挥，不批量生成
  - 每章生成前先确认该章的重点方向
  - 每章生成后用户可以要求补充、删减、修改
  - 遇到和用户个人经历相关的知识点，主动加入个人化案例
